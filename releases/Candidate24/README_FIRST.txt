Extract and keep ALL files together, including the installer GUI, PNG/ICO art, dependency helper, manifest and data parts. On Windows run Install_Nexus_AI.py for the graphical installer. Terminal fallback: python Install_Nexus_AI.py --cli. The GUI uses existing Python tkinter only; no GUI package is installed before consent. The installer previews all changes and asks permission. No shared Nexus launcher, driver, PATH or registry changes. Every distributed and extracted component is under 20 MB. You need Python 3.10+ already installed. One INSTALL confirmation approves the displayed plan, including automatic reuse of compatible dependencies and app-local installation of missing requirements. After successful installation the approved plan automatically opens this installed app full screen and closes the installer after desktop startup confirmation. Escape exits full screen; F11 toggles it, and a visible Full screen button is also available. Errors or browser-only handoffs keep the installer open. Use --no-launch to install without opening. The filling progress bar measures completed installation stages, not elapsed time or download bytes. Existing packages and drivers are left unchanged.
