# Integration contract

## Shared source and data-only imports

The local shared compression format/parser/kernel files match `SHARED_SOURCE_IDENTITIES.json`. `SHARED_SOURCE_LOCK.json` is inherited upstream-path provenance and includes older/different source identities; it is not the current local-file inventory. The generated release source manifest inventories actual packaged bytes. Changes to shared code require fresh codec, graph, lifecycle, and paired-evaluation checks. The deterministic build composes trusted runtime source; user-selected model files cannot supply executable JavaScript, dynamic kernels, WASM, or URLs to execute.

Model names and file extensions never grant graph support. Each backend owns complete metadata/layout/tensor-consumption checks, tokenizer/prompt rules, memory accounting, cancellation, and disposal. Unsupported fields and unconsumed tensors must remain explicit errors. Exact numerical reconstruction is distinct from inference parity.

The expression local-folder route is a narrowly whitelisted runtime-sidecar import: executable worker/module/WASM bytes are accepted only when their size and SHA-256 match the trusted application manifest. A file-supplied manifest is not a trust root. Ordinary model imports remain data-only.

## Composed application boundaries

The builder applies compatibility/GPU/architecture patches, compressed integration, expression replacement, UI/download features, Qwen graph/UI, backend routing, offload, voice, and session learning in their verified order. Read the actual final builder/receipt for the definitive list. Later wrappers must retain model ownership, consent validation, output-head isolation, combined student/teacher memory guards, and late-operation cancellation.

- Dense Mistral/Smol, Gemma3, Qwen2.5-VL, and GPT-oss have different graph/tokenizer contracts.
- Generic RAM-backed weight streaming does not bypass the explicit GPT-oss-120B hardware-upgrade gate.
- Qwen images require a deliberately selected still image and matching local projector. They do not enable camera capture or remote image transmission.
- Expression frames remain separate from the language-model image graph. Only the separate local-tone opt-in can add a transient uncertain label to local prompts; online prompts and training capture exclude it.
- End Session drains generation/media before approved output-head training and preserves a recoverable prior checkpoint until durable promotion succeeds.

## Numerical and memory evidence

Compression/restore must reproduce exact source bytes. Direct compressed inference and ordinary GGUF inference are separate paths. Allocation receipts distinguish packed weights, vectors, KV, activations, staging, host cache, and total owned buffers. Physical VRAM and browser/driver overhead cannot be inferred from that ledger.

Before/after model evaluations must use identical source representation, tokenizer IDs, text, windows, stride, masks, and stopping criteria. Accumulate finite losses before deriving aggregate metrics. Record skipped, failed, interrupted, and unperformed stages separately. Partial/token-level checks are not complete perplexity or quality results.

The final build is releasable as the stated experimental scope only when its hash, embedded feature source, sidecars, and final aggregate receipts agree. Browser/device and large-checkpoint gaps remain visible even if every available synthetic/host suite passes.

## Removed historical pack system

NEXVP001 general vision packs, identity enrollment/recognition, gallery/vault, scene/object/animal models, and their pack-import controls are outside this expression-only composition. Their former format/interoperability description is historical, not an available feature or instruction to bundle old packs. Preserve required legacy settings migration without restoring those executable paths.
