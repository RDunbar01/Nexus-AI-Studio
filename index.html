Local inference and controllable chat

Import local models, check engine compatibility, select a hardware profile and inspect diagnostics. Native protocol 3 adds session-scoped prefix caching, cooperative Stop and New Chat reset.

This version requires the complete download and a local service. Use CPython 3.10 or later; the recorded checks used 3.12.14. Its HTML alone is not a hosted Nexus AI trial. Native and browser engines have different model support.

Try related Nexus tools in your browser

  • Compression & Recovery Studio: low-bit compression and recovery controls.
  • Random Initialization Foundry: small-model initialization and training controls.
  • Adapter Optimization Studio: supported local adapter-training workflows.
  • Benchmark Token Studio: disposable scratch-model benchmarks.

These single-file HTML editions include their interface and browser code so evaluators can open a trial without a build step or Python installation. WebGPU and supported local inputs are needed for relevant workloads. Native PyTorch features require the separate full application download.
